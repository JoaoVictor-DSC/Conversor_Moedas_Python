# 💱 Conversor de Moedas em Tempo Real

Aplicação desktop moderna e intuitiva desenvolvida em Python para conversão de moedas internacionais em tempo real, utilizando a API da AwesomeAPI e uma interface gráfica estilizada com CustomTkinter.

---

## 🚀 Funcionalidades

* **Cotações em Tempo Real:** Integração direta com a [AwesomeAPI](https://docs.awesomeapi.com.br/) para obter taxas de câmbio atualizadas.
* **Conversão Multimoedas:** Suporte a conversões bidirecionais entre mais de 20 moedas globais (USD, EUR, BRL, GBP, JPY, CAD, entre outras).
* **Interface Gráfica Dark Mode:** Layout moderno construído com `customtkinter`, oferecendo uma experiência visual limpa e responsiva.
* **Tratamento de Erros:** Validação automática para prevenir entradas inválidas (letras), falhas de conexão de rede ou pares de moedas não suportados.
* **Exibição Dinâmica:** Painel de resultados estilizado em caixa de destaque que surge apenas após o acionamento do cálculo.

---

## 🛠️ Tecnologias Utilizadas

* **[Python 3.x](https://www.python.org/):** Linguagem principal do projeto.
* **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter):** Biblioteca para desenvolvimento da interface gráfica (GUI).
* **[Requests](https://requests.readthedocs.io/):** Consumo de APIs via requisições HTTP GET.
